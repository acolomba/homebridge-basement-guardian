# Security Policy

## Supported Versions

Basement Guardian provides best-effort support for the current stable release only, through the public [GitHub Issues](https://github.com/acolomba/homebridge-basement-guardian/issues) tracker. No response time, resolution time, continued compatibility, or service-level agreement (SLA) is promised.

Routine fixes are not backported to older release lines. If you report a problem, reproduce it on the current stable release first -- an older release line receives no further investigation.

When filing an issue, include your plugin version, Homebridge version, Node.js version, reproduction steps, and redacted logs. Never include your account password, an authentication token, or a complete `config.json`.

## Reporting a Vulnerability

Do not open a public issue for a security vulnerability. Instead, use GitHub's private Security Advisories feature:

<https://github.com/acolomba/homebridge-basement-guardian/security/advisories/new>

A private report keeps the details out of the public tracker until a fix is ready. A vulnerability report should never include your account password, an authentication token, or a complete `config.json` -- describe the issue and its impact, and share only the minimum information needed to reproduce it.
