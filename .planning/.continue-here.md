## Critical Anti-Patterns

Every row below was discovered through an actual failure in this session, not predicted.

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| A failure masked by a pipe | `pipefail` is off. `./dev/hb up 2>&1 \| tail -25` reported exit 0 while the config render had died on `EACCES`. This is the project's own named anti-pattern, committed by the orchestrator. | blocking | Capture status separately: `O=$(cmd 2>&1); R=$?`. Never pipe a command whose status you need. |
| A commit that never happened | `gitlint` rejected a 73-character title; the commit did not exist while the transcript read as though it had. Hit twice this session, once here and once in wave 2. | blocking | Keep titles ≤72 chars. After every commit run `git show --name-only --format="" HEAD` and read the file list. A rejected hook means recommit, never `--amend`. |
| `./dev/hb reset` as the way to clear pairing | It wipes all container storage, including `accessories/cachedAccessories`, which carries the pump records — an observation epoch and 15 real activations since 2026-09-02 that cannot be regenerated. | blocking | To clear pairing, delete `dev/homebridge/persist/*` only. Back it up first. Records live in accessory context in `cachedAccessories`, not in `persist/`. |
| The dev container writing `config.json` as root | Every container run leaves `dev/homebridge/config.json` and `accessories/` owned by root, so the next `./dev/hb up` dies with `EACCES` before starting. Hit three times. | advisory | `docker run --rm -v "$PWD/dev/homebridge":/s alpine:3 chown -R 1000:1000 /s` with the container down. A permanent fix belongs in `dev/hb` before `docker compose up`. |
| A gate that cannot pass on the runtime it targets | Plan 05.1-07's v22 verify asserts `^ℹ fail 0$`, but Node 22 prints TAP (`# fail 0`) in a captured run where Node 26 prints the spec line. | advisory | Assert on both forms, or assert on the exit status and the TAP counts. |
| Committing the UAT forcing harness | A temporary build overrode reported telemetry before family validation. It is reverted and `dist/` was rebuilt without it, verified by grep. | blocking | Never commit it. Rebuild it from the recipe in `04-UAT.md` when needed, and revert plus rebuild `dist/` the moment the session ends. |
