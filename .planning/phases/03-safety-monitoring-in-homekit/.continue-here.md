## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Trivially-passing assertion | Six assertions in this phase passed against absent or unpublished state: nine Cucumber `is not activated` steps passing on a value never published (`0` is both "not activated" and HAP's construction default); a SAFE-07 assertion passing because it asserts an absence; a static import gate that would have enumerated zero files; a test titled "leaves a freshly added service at its construction defaults" that existed to assert a defect as correct. | blocking | Every new assertion must be falsified: introduce the defect it claims to catch and confirm it fails. Absence assertions additionally need a positive discriminator (a floor on the enumerated count, or a `pushed === true` flag). |
| Test that encodes the bug | Five existing tests asserted buggy behaviour as correct and were rewritten in fix iteration 1; iteration 2 then found one of those rewrites had encoded a *new* contradiction. | blocking | When rewriting a test, the new assertion must be strictly stronger, not merely different. If you find a test encoding a defect, report it as a finding of its own rather than quietly rewriting it. |
| Fix introducing a blocker | Iteration 1's WR-02 fix (a `try` so one bad device cannot abort the inventory loop) swallowed a throw between caching the accessory wrapper and registering the platform accessory, blanking the device permanently. | blocking | Re-review after every fix pass, scoped to exactly the files the fixes touched. |
| `HapStatusError` as a degradation signal | Produces Apple Home "No Response", which erases the retained last-valid values `D-014` requires the accessory to keep. Looks like a fix. | advisory | `D-05`: a degraded scope sets `StatusActive = false`, retains values, logs once. Never throw from a getter. |
| Commit title over 72 characters | gitlint rejects it, the commit silently does not happen, and the agent proceeds believing it did. Cost two agents a lost commit this phase. | advisory | Keep titles ≤72 chars; verify each commit landed with `git show --name-only`. |
| Isolation sentinel not written back | `worktree base-check` degrading to sequential does not itself update the run-scoped sentinel the dispatch guard reads. The first executor dispatch was correctly refused. | advisory | After the degrade, run `gsd-tools query dispatch-isolation --raw --phase N --force-isolation none`. It goes stale after 10 minutes, so refresh before each dispatch. A plain `--json` query re-persists the *capability* and clobbers the forced value. |
