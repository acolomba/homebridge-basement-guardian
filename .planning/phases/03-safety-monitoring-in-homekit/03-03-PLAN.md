<objective>
Add the `ignoredFaults` configuration surface: the seven removable notification slugs as both a type
and a runtime list, a refusal that names a bad or duplicated slug and enumerates the valid ones, the
matching settings-form control, and the exhaustive key-set gate that proves no alert-delay setting
exists.

Purpose: `CONF-06` lets an administrator remove selected Apple Home notification adapters while every
truthful source state stays available. `D-17` decided — against the recommendation, with the trade
understood — that an unrecognised slug refuses the configuration rather than being ignored, because a
typo means the administrator did not get the configuration they asked for. The accepted risk is that a
typo in a cosmetic list leaves the pump unmonitored until someone reads the log, so the mitigation is
entirely in the message quality: naming the bad slug and enumerating the valid seven is a requirement
of that decision, not a nicety, and this plan treats it as testable behaviour. The same plan carries
the `SAFE-07` half that lives in configuration: `D-18` asks the existing schema key-set case to prove
no alert-delay setting exists, and that case grows from six keys to seven here.
Output: `'primary-pump-running'` on `CoreServiceKind`, a runtime slug list, `BgConfig.ignoredFaults`,
the shipped `ignoredFaults` control, and an exhaustive seven-key form gate.
</objective>

function describeValue(value: unknown): string {
  return typeof value === 'object' && value !== null ? JSON.stringify(value) : String(value);
}

function integerRefusal(value: unknown, bounds: IntegerBounds): string | undefined {
  if (value === undefined) { return undefined; }
  if (typeof value !== 'number' || !Number.isInteger(value) || value < bounds.minimum || value > bounds.maximum) {
    const range = `from ${String(bounds.minimum)} to ${String(bounds.maximum)}`;
    return `${bounds.field} must be a whole number of ${bounds.unit} ${range}, but it is ${describeValue(value)}.`;
  }
  return undefined;
}

function firstRefusal(fields: Record<string, unknown>): string | undefined {
