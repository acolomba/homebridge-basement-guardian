Prove the whole Phase 1 architecture on one path: a valid configuration authenticates against the vendor Auth0 tenant, discovers devices over REST, produces one canonical snapshot per device in the store, and shuts down cleanly on the Homebridge shutdown event.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| administrator `config.json` → plugin | Hand-edited configuration reaches the runtime; `strictValidation` guards only the UI form. |
| plugin → vendor Auth0 tenant | The account password crosses this boundary in a request body that is a secret in its entirety. |
| vendor REST API → plugin | Untrusted, untyped JSON becomes canonical safety state. |
| plugin → Homebridge log | Every error object and message is a potential secret egress path. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-05 | Information disclosure | `src/cloud/auth.ts` failure path | high | mitigate | Throw typed errors carrying only the HTTP status and the parsed `error` code; log a fixed message plus the status and never the request body, a header, or a response body. The structural redacting wrapper in plan 04 makes this an enforced invariant rather than a convention. |
| T-01-06 | Tampering | `src/cloud/types.ts` wire boundary | high | mitigate | Type every response as `unknown` and narrow with `isApiDevice` / `isApiDeviceList`; reject a malformed payload with `CloudRequestError` instead of admitting it to the store. No assertion syntax anywhere at the boundary. |
| T-01-07 | Spoofing | `src/cloud/api.ts` authorization | medium | mitigate | The `Authorization` header is built from the auth client's token on every request; the header value is never logged and never placed in an error's `route` field. |
| T-01-08 | Denial of service | `src/runtime/accountRuntime.ts` lifecycle | medium | mitigate | One root `AbortController` owns every in-flight request; `stop()` aborts once and is idempotent, so a shutdown during discovery cannot leave a pending fetch or raise an unhandled rejection. |
| T-01-09 | Information disclosure | `src/protocol.json` | low | accept | The file holds six public vendor protocol constants. `REL-04` explicitly carves out the bundled data file as the one permitted location for them, giving secret and identifier scans a single known allowlist path. Accepted with that carve-out as the rationale. |
