<objective>
Build the two pure pieces the shadow transport stands on: a deterministic AWS IoT URL signer and a capped, guarded, abortable retry policy.

Purpose: research established that AWS validates the signature only at the WebSocket handshake and publishes a twenty-four-hour maximum connection duration, so an established connection outlives the roughly one-hour credentials that signed it. Rotating credentials therefore means keeping a cache fresh for the *next* handshake, and the signing hook that reads that cache is synchronous. No library exposes a JavaScript credentials delegate, so the signer is ours — the one deliberate exception to the do-not-hand-roll rule, and the reason it is safe is that it is a pure function of credentials plus a clock with no state at all, which golden-vector tests can pin completely. The retry policy is separated because a duplicate failure notification is the classic source of a doubled reconnect loop.

Output: a signer whose output is pinned by an independently computed vector, and a retry policy whose backoff table, guard, and abort behavior are each asserted.
</objective>

```typescript
export interface RetryPolicyOptions {
  clock: Clock;
  signal: AbortSignal;
  maxDelayMs: number;
  log: Logging;
}
export interface RetryPolicy {
  readonly attempt: number;
  readonly pending: boolean;
  nextDelayMs(): number;
  schedule(run: () => Promise<void>): void;
  reset(): void;
}
export function createRetryPolicy(options: RetryPolicyOptions): RetryPolicy;
```

The signed URL's shape, from the AWS Signature Version 4 specification plus the AWS IoT specifics:

- Path is `/mqtt`. Service name is `iotdevicegateway`. Signed headers are `host` only.
- The signed query string, in this exact order: `X-Amz-Algorithm`, `X-Amz-Credential`, `X-Amz-Date`,
  `X-Amz-SignedHeaders`.
- `X-Amz-Credential` is the access key id, the eight-digit date stamp, the region, the service name,
  and `aws4_request`, joined by `/` and percent-encoded as one value.
- The payload hash is the SHA-256 digest of the empty string.
- `X-Amz-Signature` is appended after the signed query string, and `X-Amz-Security-Token` is appended
  **after** the signature and is percent-encoded. AWS IoT is one of the services that takes the
  security token outside the canonical query string; the AWS SDK signer cannot produce this form,
  which is why the canonicalization is ours.

The backoff table this plan pins, with `maxDelayMs` of 30000 and a one-based attempt counter:

| attempt | delay in milliseconds |
|---|---|
| 1 | 500 |
| 2 | 1000 |
| 3 | 2000 |
| 4 | 4000 |
| 5 | 8000 |
| 6 | 16000 |
| 7 | 30000 |
| 8 and beyond | 30000 |

Own the backoff here rather than letting the transport client own reconnect timing. `schedule(run)` sets a pending flag, waits the next delay, invokes the work, and clears the flag in a `finally` so a rejection cannot strand the guard. `reset()` returns the attempt counter to zero and is called by the consumer after a successful connection, so a later isolated failure retries quickly rather than at the previous cap.

Enable only the timer API the module uses when scheduling itself is the behavior under test, and advance it explicitly; do not await a real timer and do not poll.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| temporary AWS credentials → signed URL | Credential material and a signature are embedded in a URL string that is easy to log by accident. |
| plugin → AWS IoT message broker | The handshake is the only point at which authorization is checked. |
| transport failure notifications → retry scheduling | Duplicate notifications drive duplicate work if unguarded. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |

| T-01-34 | Spoofing | signature correctness | high | mitigate | The signature is pinned by an independently computed vector and by sensitivity cases for the secret, region, host, and clock. A signing defect fails loudly at the handshake with HTTP 403 rather than silently degrading. |
