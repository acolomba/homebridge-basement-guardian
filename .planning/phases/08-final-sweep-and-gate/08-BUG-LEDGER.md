The original [Phase 1](../01-known-findings-and-loop-proof/01-FINDINGS.md), [Phase 2](../02-cloud-conformance/02-FINDINGS.md), [Phase 3](../03-device-and-persistence-conformance/03-FINDINGS.md), [Phase 4](../04-runtime-conformance/04-FINDINGS.md), [Phase 5](../05-accessories-conformance/05-FINDINGS.md), [Phase 6](../06-root-module-conformance/06-FINDINGS.md) and [Phase 7](../07-cucumber-feature-conformance/07-FINDINGS.md) ledgers supply the full original candidate classifications. The [Phase 6 advisory disposition](../06-root-module-conformance/06-REVIEW-DISPOSITION.md) supplies its two additional behavior defects. This index includes every row those ledgers explicitly classify as a genuine behavior bug, including stand-in bugs. All other accepted findings retain their original test-strength, style, documentation, or conformance classification; rejected candidates remain rejected.

For all **48 archive rows**, the exact native record at its evidence commit has exit 1, names the failing target in its output, and records an intended assertion failure with no skipped or cancelled target. The applicable archive's current top-level `tdd-red-evidence --raw` check returned exit 0, `RED_EVIDENCE_OK`, and `target_test_failed`. Git `merge-base --is-ancestor` confirmed source < evidence < fix < this branch HEAD for all 48. `git show --name-only` confirmed each evidence commit changes only planning paths and each listed fix changes the owner source and/or active regression. `git rev-parse <source>:<production path>` equals the corresponding evidence blob for all 48. These are independently checked Git objects, not inferred from commit subjects.

The archive's full native output, command, source revision, patch, runtime, and timestamp are linked in each row. The table gives a short assertion excerpt; the full record is authoritative. Older records inside `priorEvidence` were inspected at their own evidence commits. Current named test text was inspected in source. Some current cases use a dynamic title; the table gives the concrete rendered RED title. **No owner or build test was rerun in this delegated audit.** Prior GREEN claims remain in the phase ledgers, and a fresh gate on the final tree belongs to the parent coordinator.
