<objective>
Persist the wall-clock arrival anchor, so the clamp plan 05.1-04 built survives a restart.

Purpose: the monotonic term resets to zero when the process does. Without a persisted wall anchor a
restart re-vouches for a pump that has been quiet for hours, which is the same false normal on a
slower clock. The anchor lives in its own store under `api.user.storagePath()` rather than in
accessory context, and that is settled: `health.admitDevice` runs at
`src/runtime/accountRuntime.ts:343-349`, **before** `onTrustworthyInventory` at `:351-352` builds the
accessories, so at the moment the runtime needs the anchor no accessory exists for that device — and
`accountRuntime.ts` imports nothing from the persistence tier.

Output: a small runtime-scoped store following the token cache's shape, wired where the failure log
already is, restored before the launch and pruned where stamps are.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| filesystem → plugin | A new JSON file under `api.user.storagePath()` is read at every launch. Its contents are untrusted stored input: anything on disk, whatever the declared type promises. |
| plugin → filesystem | The same file is written on the reporting tick. A partial write must not be readable as a whole one. |
