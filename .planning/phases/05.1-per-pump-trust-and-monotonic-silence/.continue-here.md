## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| A branch forked from `origin/main` | `execute-phase`'s `handle_branching` and the worktree harness both fork from `origin/HEAD`. **Measured 2026-09-03: `origin/main` is 552 commits behind and five of the six files this phase edits do not exist there** — `monitoringHealth.ts`, `clock.ts`, `basementGuardian.ts`, `test/platform.test.ts`, `features/support/world.ts` all absent; only `platform.ts` present. An executor there has nothing to edit and may write the files instead. `worktree.base-check` independently returns `shouldDegrade: true`, reason `baseref-head-ignored-by-harness`. | blocking | Stay on `features/phase-05-degraded-operation-and-recovery`. Maintainer ruling, 2026-09-03. Before accepting any branch the tooling proposes, run `git cat-file -e origin/main:<path>` on the files the plan edits. |
| Executor dispatch blocked by the isolation guard | `dispatch-isolation` reports the host capability while `worktree base-check` says degrade. A mismatch denies with exit 2 and the task never runs. | blocking | Force before **every** dispatch: `gsd-tools query dispatch-isolation --raw --phase 05.1 --force-isolation none`, then verify by **reading** `.gsd/dispatch-isolation-sentinel.json`. Never verify by re-querying — a bare query re-persists the capability and undoes the force. |
| A gate or a report that cannot fail because of how it is piped | `pipefail` is **off**: `npm run test:x \| grep y` returns *grep's* status. Proven: `(exit 7) \| grep x` returns 1. **Two silent non-commits were caught this phase by checking content instead of output** — a planner's commit hidden by `\| tail -3`, and a `gitlint` rejection of a 74-character title hidden by `\| tail -2`. | blocking | Capture both: `O=$(npm test 2>&1); R=$?; test $R -eq 0 && printf '%s\n' "$O" \| grep -qE '^ℹ fail 0$'`. After every commit run `git show --name-only --format="" HEAD`; an empty list means it did not happen. Keep commit titles ≤72 chars. A rejected hook means the commit never happened — recommit, never `--amend`. |
| A check that passes because the thing it rests on already sits at the value the defect produces | Phase 05's defining defect. **Hit at least six more times in this phase**, most usefully sharpened by wave 2: what defeats a mutation is **an expectation that already equals the default the defect produces** — not the size of the fixture. A single-accessory case *did* catch the broken UUID join. Wave 3's instance: without `store.remove(deviceId)` in the harness, the retained kind is swept by the next poll and V15 fails nothing. | blocking | `05.1-VALIDATION.md` names the discriminating mutation for all 15 rows and is binding. Apply it, watch the named test fail, revert, confirm green, **record which test failed on what line**. A mutation that fails nothing is a finding to report, not a failure to hide. |
| The type system will not protect a callback signature change | Measured in wave 2: TypeScript accepts a callback that ignores an added parameter, so `test/runtime/accountRuntime.test.ts` compiled clean while **17 cases failed at runtime and 18 assertions changed semantically with no compiler help**. | advisory | Never treat a clean `npm run typecheck` as evidence that call sites are correct after a signature change. Run the unit suite. |
| A false red from concurrent builds | Every suite command rebuilds the shared `dist-test/` tree. Measured: solo `1385 / fail 0`, concurrent `pass 1383 / fail 2`. | advisory | One suite at a time — which is why all seven plans are separate waves. If a gate goes red, **re-run it alone before believing it**, and say so in the SUMMARY if you had to. |
| Reverting a mutation with `git checkout --` against a moved HEAD | Wave 3 ran `git checkout -- src/runtime/accountRuntime.ts` while HEAD was still the RED commit and discarded its own uncommitted GREEN edit. Caught immediately by `git status --short`; nothing lost. | advisory | Revert mutations from a filesystem copy, not from git, whenever uncommitted work is in the tree. |
