## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
| --- | --- | --- | --- |
| Consumer checks limited to named consumers | The RECORDS 002 fix changed a persisted shape. Its consumer run covered basementGuardian and Cucumber, but not `test/platform.test.ts`, which then failed until a declared adaptation fixed it. | blocking | Every production fix runs every unit module (`node --test $(find dist-test/test -name '*.test.js' \| sort)`) and the whole Cucumber suite before its commit. |
| zsh word-splitting and modifiers | `T="node x"; $T ...` does not split (command not found, hidden by `2>/dev/null`). `$E:path` applies a zsh modifier. `PIPESTATUS` is unset. | blocking | Use arrays (`F=(...)`, `"${F[@]}"`) or call `node $T` with `T` holding only the path. Write `"${E}:path"`. Never pipe a command whose raw exit matters. |
| Hand-typed fix hashes | A mistyped hash (`1f85938659` for `1f8593865e`) failed tracer L3. | blocking | Record hashes from `git rev-parse --short=10 <hash>` or from tool output, never from memory. |
| Comment-claim churn | A fixer's comment rewrite often adds a new claim that is close but not exact, and the next round files it. | advisory | Reviewer prompts check every comment clause against the code. Fixer prompts say "say less; add no unchecked claim". When a class keeps returning, record a claims audit table. |
| Pausing at a forbidden point | The protocol forbids pausing between a reviewer result and its counter row, or inside a cause, D-04 or D-06 sequence. | blocking | Pause only at resume points (a) or (b). Record the `#### Resume point` entry and commit the ledger alone. |
| GSD commit wrappers and WIP titles | `gsd-tools query commit` can commit nothing; AGENTS.md and the memory forbid WIP titles. | blocking | Run `SKIP=npm-check pre-commit run --files <paths>`, `git add -- <paths>`, then a plain foreground `git commit` with a `docs:`/`test(...)`/`fix(...)` title and the Co-Authored-By line. |
