report, the reports R1 to R10 (a reviewer writes one only for a round that runs) and one RED
evidence file (only for a confirmed bug). Reviewers and fixers read the 1,044 source and 2,291

report's findings, round status and cited lines and the command results: round 0 with triage
and the tracer cause about 35K, the round-0 repair pass about 20K (one fixer dispatch per
file), each correction round with its repairs about 20K, and the closing gate about 6K. The
estimate assumes three correction rounds, as Phase 4's batches needed two or three: about 195K.

`context_window` in `.planning/config.json`, inside the ~50% per-plan target. The estimate is
over the 100,000-token smart-zone default, which is an advisory flag. The plan is not split:
every committed counter row and every committed record of a dispatch's fix commits is a resume
point, so a pause between rounds loses no work and needs no second plan.
