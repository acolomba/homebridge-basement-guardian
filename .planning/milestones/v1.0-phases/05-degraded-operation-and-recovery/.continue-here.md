## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| A gate that cannot fail because of how it is piped | `pipefail` is **off** in this shell, so `npm run test:x \| grep y` returns *grep's* status and npm's failure is discarded. Proven: `(exit 7) \| grep x` returns 1. A plan shipped with five such gates — a red suite would have reported success, and the counts the task depended on lived only in prose. | blocking | Capture and assert both: `O=$(npm run test:unit 2>&1); R=$?; test $R -eq 0 && printf '%s\n' "$O" \| grep -qE '^ℹ fail 0$'`. Never pipe a suite command directly into a filter inside a `<verify>` block. |
| A check that passes because the thing it rests on already sits at the value the defect produces | The phase's defining defect, now seen at **four layers**: in shipped code, in the tests meant to pin it, in the validation records, and in a plan written to correct a validation record. Instances: a fixture at `water_level: 2` outside the legal domain; `world.ts` calling the marking function directly so deleting the production call site left Cucumber green; a `grep -c` floor already satisfied before its plan started; a static gate counting a marker that appears ten times and is unique to none of them. | blocking | For every safety-bearing claim, apply the named mutation, watch the specific test fail, revert, confirm green — and record which test failed and on what line. Before trusting a new assertion, ask whether its expected value is already what the field holds. `05-VALIDATION.md` names the mutation for each row and is binding. |
| A quick-task branch forked from `origin/main` | `/gsd-quick` and the worktree harness both default to forking from `origin/HEAD`. `origin/main` is **525+ commits behind** and contains no Phase 3, 4 or 5 source — `git cat-file -e origin/main:.planning/phases/05-.../05-VALIDATION.md` fails. A branch cut there would hand an executor a tree with nothing to edit. | blocking | Stay on `features/phase-05-degraded-operation-and-recovery`. Before accepting any branch the tooling proposes, verify the files the task edits exist on its base. |
| Executor dispatch blocked by the isolation guard | `dispatch-isolation` reports the host capability (`harness-worktree`) while `worktree base-check` returns `shouldDegrade: true`, because a harness worktree forks from `origin/HEAD`. A mismatch between the sentinel and the dispatch makes the guard deny with exit 2 — the task does not run at all. | blocking | Force it before **every** dispatch: `gsd-tools query dispatch-isolation --raw --force-isolation none`, then verify by **reading** `.gsd/dispatch-isolation-sentinel.json`. Never by re-querying — a bare query re-persists the capability and undoes the force. |
| A false red from concurrent builds | Every suite command rebuilds the shared `dist-test/` tree, and a second Claude session may share this working tree. Two overlapping `npm run check` runs were measured: the solo run gave `1385 / fail 0`, the concurrent one gave `pass 1383 / fail 2`. | advisory | Run one suite at a time. If a gate goes red, **re-run it alone before believing it**, and say in the summary if you had to. |
| A subagent reporting a commit hash that does not exist | Observed on this project. Also: `gsd-tools query commit` can report success while committing nothing, and the pause workflow's own `wip:` prefix is rejected by this repo's gitlint T5 rule. | advisory | Verify by content: `git show --name-only --format="" HEAD`. Use plain git: `pre-commit run --files <paths>` → `git add` → `git commit` with no pathspec → verify. Never `--no-verify`, never rebase. |

keep asking for null results — "this mutation failed nothing" was repeatedly more useful than a clean
sweep.

code was unnecessary and should be deleted. The reasoning was sound; the premise was not. The guard
was real, and what was wrong was the reason recorded for it. Correcting a justification can matter as
much as correcting behaviour, because a false justification is what makes correct code look deletable.
