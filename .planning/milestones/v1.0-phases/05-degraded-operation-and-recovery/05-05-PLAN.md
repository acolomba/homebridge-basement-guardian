<objective>
Close the phase: prove no threshold became a setting, tell the user what the new degradation states
mean, and stop `REQUIREMENTS.md` contradicting itself.

resistance be deliberate rather than incidental — so it gets an assertion. The poll-interval bound on
detection latency is a real cost of the design that research accepted explicitly, and it belongs in
the README rather than in a knob. And `REQUIREMENTS.md` has marked RES-01 and RES-03 complete since
Phase 3 while its own inline notes say Phase 5 still owes part of both; leaving that means this
phase's delivery cannot be tracked and a later audit reads both as already shipped.
Output: the configuration gate, the user-facing account of the new states, and a traceability table
that agrees with itself.
</objective>
