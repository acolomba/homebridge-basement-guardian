## Context

The Phase 4 verifier route's fresh advisory review found two current defects
in the Phase 8 tree: a JSON-escaped registered credential can reach a
Homebridge logger through an `Error` parameter, and an arrival-anchor
ordering test can pass a non-serializing implementation after its 100 ms
fallback. Evidence is in `04-REVIEW.md`. The original Phase 8 STOP and
subsequent correction rounds remain historical. Phase 4 verification stays
stale until the corrected source is sealed.

## Tasks

   `CR-08-RUNTIME-007` for the weak ordering assertion. Obtain an active,
   named logger regression failure on unchanged production. Retain its patch,
   command, complete native output, source revision, and intended failure in
   a planning-only RED record and commit it before the fix. The test-strength
   finding needs a negative control against a non-serializing writer, not a
   claim of a production RED.

   JSON-escaped text on every logging route. Strengthen the ordering test

   owner tests and isolated direct coverage for both changed pairs. Commit
   each cause separately with normal hooks.
3. Run the full combined gate. Have independent reviewers read the complete
   current `src/logging.ts`, `test/logging.test.ts`, and
   `test/runtime/arrivalAnchors.test.ts` blobs. Record ROOT round 2 and
