# Replace accessory source scanners with lint rules

Commit `3299b7e` removed the three source-scanning tests and their shared parser
(4,377 lines). `eslint.config.js` now rejects direct HAP imports outside the real-HAP
parity test, dynamic module loading, Node timer imports from accessories, direct
accessory imports of cloud/account runtime modules, HomeKit read registration, and
write registration outside `controls.ts`. The two test registries no longer list
the removed tests. The real-HAP parity test and runtime tests remain.

## Verification

- ESLint probes reported the intended restrictions for direct and subpath HAP
  imports, re-exports, timers, vendor imports, dynamic loading, and read/write
  registration. Current `controls.ts` and the parity test passed lint.
- `npm_config_cache=/private/tmp/basement-guardian-npm-cache npm run
  test:unpaired:compiled`: exit 0. The temporary cache avoids unrelated
  root-owned files in the default npm cache.
- `./node_modules/.bin/fallow audit --base HEAD`: exit 0, no issues in the
  changed files. It needed temporary Git worktree access.
- Commit hook: exit 0, including `check:commit`.
- `npm_config_cache=/private/tmp/basement-guardian-npm-cache npm run check`:
  exit 0 after commit `3299b7e` on Node v26.12.0. All 104 Cucumber scenarios,
  1,156 steps, and direct coverage for 43 source/test pairs passed. The command
  needed local socket access for Cucumber's fake services.

## Limits

These lint rules cover static imports and ordinary registration syntax. They do
not attempt to interpret arbitrary aliases or computed event names. Exact source
counts for UUID generation and the persistent-error characteristic were retired
with the scanners. Runtime and parity tests continue to check behavior, and code
review covers unusual syntax.

The Phase 5 GATES ledger and round-15 report remain unchanged and uncommitted.
The existing Phase 5 closeout plan still assumes a clean review of the retired
scanner tests. It needs a separate planning update before Phase 5 closeout.

## Threat Flags

None -- no security-relevant surface outside the plan's `<threat_model>` was introduced.
